## 1. alchaincyf/zhangxuefeng-skill(原版 / 花叔)
- 链接:https://github.com/alchaincyf/zhangxuefeng-skill
- 定位:"张雪峰的认知操作系统"——高考志愿/考研/职业规划的实战思维框架。
- 来源声明:从 5 本书 + 15+ 媒体访谈蒸馏。
- 关键心智模型:就业反推(employment reverse-engineering)、家庭资源分诊(family-resource triage)。
- 用法:可直接把 SKILL.md 内容贴进对话;复刻张雪峰用词/节奏/幽默/果断下结论的风格。
- **短板(社区共识)**:只有情绪价值,数据不保真,时效停在素材出版时。

## 2. Eric-Yibo-Shen/zhangxuefeng-skillset
- 链接:https://github.com/Eric-Yibo-Shen/zhangxuefeng-skillset
- 定位:多端部署——Coze Web Agent / 扣子技能商店 / Claude Code(`npx skills add eric-yibo-shen/zhangxuefeng`)/ 抖音扣子多智能体。
- 借鉴点:工程化部署路径(尤其 Claude Code 接入方式)。

## 3. a18515373115-droid/ZhangXueFeng-skill(数据保真迭代版)
- 链接:https://github.com/a18515373115-droid/ZhangXueFeng-skill
- 自述:用女娲 skill 捏的原版"只有情绪、缺数据准确性",于是迭代到数据更准、能真正给高考决策依据的版本。
- **方向与本项目一致**——重点研究它如何做就业/薪资数据的来源标注与保真。
